# CX-Util-Lib
CX-Util-Lib contains implementations of common utility structures such as optionals, pairs, results, arrays and more. This was a learning project where I learned to write library code.

## Usage
This library contains no source files and you can use it by downloading the include folder and including it into your project. This library only depends on C++20.
